## 十一、信息安全（4-6题，必拿分）

### 11.1 加密技术（必考）

| 类型 | 算法 | 密钥 | 速度 | 用途 |
|------|------|------|------|------|
| **对称** | DES(56位，已淘汰)、3DES、AES(128/192/256)、IDEA、RC4、RC5 | 同一把 | 快 | 大数据加密 |
| **非对称** | RSA、ECC、DSA、ElGamal、Diffie-Hellman | 公私钥对 | 慢 | 密钥分发、签名 |
| **摘要** | MD5(128，已不安全)、SHA-1(160，已不推荐)、**SHA-256/SHA-3、SM3** | 无 | 快 | 完整性校验 |

> 安全提示：**MD5 和 SHA-1 均已被证明存在碰撞攻击**，不推荐用于安全敏感场景（如证书签名、密码存储）。新系统应使用 SHA-256/SHA-3 或国密 SM3。

**国密算法**：
- SM1：对称（硬件实现）
- SM2：非对称（基于 ECC）
- SM3：摘要（256 位）
- SM4：对称分组（128 位）

### 11.2 数字签名 + 数字信封（必考）

**核心口诀**：**私钥签名，公钥验证；公钥加密，私钥解密**

**完整流程（同时保证机密性、完整性、不可抵赖）**：
1. 发送方对**消息**做摘要，用**自己私钥**加密摘要 → 数字签名
2. 发送方用**对称密钥**加密（消息+签名）→ 密文
3. 发送方用**接收方公钥**加密对称密钥 → 数字信封
4. 一起发送
5. 接收方用**自己私钥**解开数字信封，得到对称密钥
6. 接收方用对称密钥解密得到消息+签名
7. 接收方用**发送方公钥**验证签名（解密摘要并对比新摘要）

**数字证书**：CA 机构签发，包含公钥、所有者信息、CA 签名
**PKI 组成**：CA、RA、证书库、密钥备份/恢复、证书撤销 CRL、应用接口

### 11.3 安全协议

| 协议 | 层次 | 用途 |
|------|------|------|
| **SSL/TLS** | 传输层 | HTTPS 基础（443） |
| **IPSec** | 网络层 | VPN 基础，AH(认证)/ESP(加密) |
| **PGP** | 应用层 | 邮件加密 |
| **S/MIME** | 应用层 | 邮件加密 |
| **HTTPS** | 应用层 | HTTP+SSL/TLS |
| **Kerberos** | 应用层 | 票据认证（KDC、AS、TGS） |
| **SET** | 应用层 | 电子支付 |

### 11.4 安全攻击分类

**被动攻击**（不修改）：
- 窃听、流量分析

**主动攻击**（修改/伪造）：
- 中断（破坏可用性）
- 篡改（破坏完整性）
- 伪造（破坏真实性）
- 重放
- 拒绝服务 DoS / DDoS

### 11.5 常见 Web 攻击

| 攻击 | 原理 | 防御 |
|------|------|------|
| SQL 注入 | 拼接 SQL 语句 | 参数化查询、输入校验 |
| XSS（跨站脚本） | 注入恶意脚本 | 输出转义、CSP |
| CSRF（跨站请求伪造） | 利用已认证会话 | Token、Referer 校验 |
| 会话劫持 | 窃取 Cookie | HTTPS、HttpOnly |
| 文件上传漏洞 | 上传木马 | 类型校验、路径隔离 |
| 命令注入 | 拼接系统命令 | 白名单校验 |

### 11.6 安全等级保护（等保2.0）

5 级：用户自主保护级 → 系统审计保护级 → 安全标记保护级 → 结构化保护级 → 访问验证保护级

### 11.7 防火墙

- 包过滤（网络层）：基于 IP/端口
- 应用代理（应用层）：深度检测
- 状态检测（结合）：现代主流
- DMZ（非军事区）：放置对外服务（Web、邮件）

### 11.8 访问控制模型

- DAC：自主访问控制（主体决定）
- MAC：强制访问控制（系统决定）
- RBAC：基于角色（最常用）
- ABAC：基于属性
