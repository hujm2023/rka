## 十四、2024-2026 题风映射（速记）

| 新题风关键词 | 本质考点 | 推荐应对 |
|-------------|---------|---------|
| 架构治理、技术债、演化 | 架构评估 + 演进式设计 | ADR + 评审 + 度量闭环 |
| 云原生数据库、存算分离 | 分布式数据库 + 性能/一致性 | 读写分离、分层缓存、容灾 |
| 信创适配、国产化迁移 | 兼容性 + 风险管理 + 安全合规 | 分阶段迁移 + 双轨验证 + 回退 |
| 端边云协同、低时延 | 分布式架构 + 通信系统 | 分层部署 + QoS + 边缘自治 |
| 秒杀/高并发场景 | 性能优化 + 高可用 + 一致性 | 限流/削峰/异步/补偿 |
