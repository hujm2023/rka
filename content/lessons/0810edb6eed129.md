## 二、操作系统（4-6题）

### 2.1 进程管理（必考）

**进程三态/五态**：
- 三态：就绪 ⇄ 运行 → 阻塞 → 就绪
- 五态：增加新建、终止
- 注意：阻塞→运行 不存在；运行→就绪 是时间片用完

**线程 vs 进程**：
- 进程是资源分配单位，线程是 CPU 调度单位
- 同一进程的线程共享：代码段、数据段、打开的文件
- 线程独立的：栈、寄存器、程序计数器

### 2.2 PV 操作（每年必考1-2题）

```
P(S): S = S - 1; if S < 0 then 阻塞
V(S): S = S + 1; if S ≤ 0 then 唤醒
```

**经典模型套路**：
- **生产者-消费者**：empty(初值=N缓冲区数)、full(初值=0)、mutex(=1)
  - 生产者：P(empty), P(mutex), 生产, V(mutex), V(full)
  - 消费者：P(full), P(mutex), 消费, V(mutex), V(empty)
- **顺序应是 资源P → 互斥P → 临界区 → 互斥V → 资源V**（顺序错会死锁）

**前趋图转 PV**：每条弧对应一个信号量(初值0)，前节点 V，后节点 P

### 2.3 死锁

**死锁四个必要条件**（缺一不可）：
1. 互斥
2. 请求与保持（占有并等待）
3. 不可剥夺（不可抢占）
4. 循环等待（环路等待）

**死锁处理策略**：
- 预防：破坏4个条件之一
- 避免：银行家算法
- 检测：资源分配图化简
- 解除：资源剥夺、撤销进程、回滚

**最少资源数公式**：n 个进程，每个需要 m 个同类资源，**不发生死锁**最少资源数 = n×(m-1)+1

### 2.4 存储管理

**分页 vs 分段 vs 段页式**：
| 维度 | 分页 | 分段 | 段页式 |
|------|------|------|--------|
| 大小 | 固定 | 不固定 | 段不固定/页固定 |
| 逻辑性 | 无 | 有 | 有 |
| 共享 | 难 | 易 | 易 |
| 碎片 | 内部碎片 | 外部碎片 | 内部碎片 |

**逻辑地址转换**：
- 分页：页号 × 页大小 + 页内偏移
- 注意页号转换为内存块号需查页表

**页面置换算法**：
- **OPT(最优)**：理想情况，无法实现
- **FIFO**：可能产生 Belady 异常（增加页框反而缺页增加）
- **LRU**：最近最久未使用（栈/链表实现）
- **LFU**：最少使用频率
- **NUR/Clock**：近似 LRU

**缺页率题套路**：
- 给定页面访问串和页框数，逐步模拟，标记缺页
- 缺页率 = 缺页次数 / 总访问次数

**工作集**：进程在某段时间内访问的页面集合，用于防止抖动

### 2.5 文件管理

- **索引文件**：直接索引、一级间接、二级间接、三级间接（题目常考最大文件大小计算）
- **位示图**：每位代表一个物理块（0空闲/1占用），第 i 个字第 j 位 → 块号 = i×字长 + j
- **目录结构**：单级、两级、树形（最常用）、图状（共享）

### 2.6 设备管理与SPOOLing

- **SPOOLing**（假脱机）：低速设备 → 高速磁盘 → 共享利用，使独占设备变为虚拟共享设备
- 三大组成：输入井/输出井、输入/输出缓冲、输入/输出进程

### 2.7 嵌入式 RTOS（实时操作系统）

- **硬实时**：必须在截止时间前完成（医疗、航天）
- **软实时**：偶尔超时可接受（视频流）
- **调度算法**：
  - RM（速率单调）：周期短优先级高（静态）
  - EDF（最早截止期优先）：动态，CPU利用率可达100%
  - 优先级反转：低优先级持有锁阻塞高优先级 → 优先级继承/天花板协议解决
