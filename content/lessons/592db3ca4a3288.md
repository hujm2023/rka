## 八、设计模式（必考3-5题，重点掌握识别）

### 8.1 GoF 23 种设计模式速记

#### 创建型（5 个）—— 解决"怎么创建对象"

| 模式 | 核心 | 识别词 | 应用 |
|------|------|--------|------|
| **工厂方法** Factory Method | 子类决定实例化哪个类 | "让子类决定" | JDBC Connection |
| **抽象工厂** Abstract Factory | 创建产品族 | "产品族"、"风格主题" | UI 主题、跨平台 |
| **建造者** Builder | 分步构建复杂对象 | "分步构造"、"装配" | StringBuilder、SQL 构造 |
| **原型** Prototype | 通过克隆创建 | "克隆"、"复制" | Cloneable |
| **单例** Singleton | 仅一个实例 | "唯一"、"全局点" | 配置、日志、连接池 |

**工厂方法 vs 抽象工厂**：
- 工厂方法：一个产品等级
- 抽象工厂：多个产品等级，构成产品族

#### 结构型（7 个）—— 解决"如何组合类与对象"

| 模式 | 核心 | 识别词 |
|------|------|--------|
| **适配器** Adapter | 接口转换 | "兼容"、"接口不符" |
| **桥接** Bridge | 抽象与实现分离 | "两个独立维度" |
| **组合** Composite | 树形结构 | "部分-整体"、"递归" |
| **装饰器** Decorator | 动态增加职责 | "动态"、"扩展功能" |
| **外观** Facade | 子系统统一入口 | "简化接口"、"门面" |
| **享元** Flyweight | 共享细粒度对象 | "大量"、"共享"、"内/外部状态" |
| **代理** Proxy | 控制访问 | "代理"、"远程"、"延迟"、"保护" |

**装饰器 vs 代理**：
- 装饰器：增强对象功能（透明）
- 代理：控制对原对象访问（可能不增强）

**适配器 vs 桥接**：
- 适配器：解决已有接口不匹配（事后补救）
- 桥接：设计阶段分离抽象与实现（事前规划）

#### 行为型（11 个）—— 解决"对象间如何协作"

| 模式 | 核心 | 识别词 |
|------|------|--------|
| **职责链** Chain of Responsibility | 多对象处理请求 | "审批"、"链式" |
| **命令** Command | 请求封装为对象 | "请求"、"撤销/重做"、"队列" |
| **解释器** Interpreter | 文法解释 | "DSL"、"语法树" |
| **迭代器** Iterator | 遍历不暴露内部 | "遍历"、"集合" |
| **中介者** Mediator | 通过中介通信 | "解耦交互"、"中心" |
| **备忘录** Memento | 保存恢复状态 | "快照"、"撤销"、"存档" |
| **观察者** Observer | 一对多通知 | "发布-订阅"、"通知" |
| **状态** State | 状态改变行为改变 | "状态切换"、"内部状态" |
| **策略** Strategy | 算法可替换 | "算法族"、"切换算法" |
| **模板方法** Template Method | 算法骨架 | "骨架"、"钩子"、"步骤固定" |
| **访问者** Visitor | 双分派、不修改类增加操作 | "对每个元素"、"多种处理" |

**易混辨析**：
- **状态 vs 策略**：结构相同，但状态会自动切换，策略由客户端选择
- **策略 vs 模板方法**：策略组合（运行时切换），模板继承（编译时确定）
- **观察者 vs 中介者**：观察者一对多直接通知；中介者多对多通过中介
- **命令 vs 策略**：命令封装请求（含历史/回退），策略封装算法
