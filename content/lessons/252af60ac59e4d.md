## 十四、11 大主题论文模板归纳速查

| 主题 | 核心理论 | 必备论点 | 数据指标 |
|------|---------|---------|---------|
| **微服务** | 单一职责/独立部署/去中心化 | 拆分、通信、注册、配置、网关、事务、监控、CI/CD | TPS/QPS/部署频率 |
| **架构评估** | ATAM 9步/4 种点/效用树 | 商业目标、效用树、敏感点、权衡点、风险点、改进 | 风险减少 X 个 |
| **高可用** | MTBF/MTTR/可用性公式 | 冗余、检测、转移、限流降级、多活、备份、监控 | 99.99%、宕机 < X 分 |
| **数据架构** | OLTP/OLAP/Lambda/Kappa | 分库分表、读写分离、缓存、中台、数仓分层、流批 | 查询时延、复用率 |
| **安全架构** | CIA/等保/纵深防御 | 认证授权、加密、防注入、CSRF、审计、DDoS、运营 | 攻击拦截数、漏洞修复率 |
| **设计模式** | GoF 23 种 | 策略、工厂、观察者、装饰器、责任链、单例 | 代码减少%、效率提升% |
| **Serverless** | 事件驱动/FaaS/BaaS | 函数拆分、状态外置、弹性、冷启动、监控 | 成本下降、扩容速度 |
| **性能优化** | 负载/压力/容量/稳定性测试 | 目标、模型、压测、瓶颈、分层优化 | P99、TPS、错误率 |
| **信创适配** | 自主可控/兼容迁移 | 依赖梳理、适配、迁移、验证、合规 | 兼容率、性能达标率 |
| **企业架构** | BSP/TOGAF/四层架构 | 蓝图设计、分阶段迁移、治理机制、标准统一 | 复用率、交付周期 |
| **架构治理** | ADR/评审/技术债治理 | 决策留痕、质量门禁、债务偿还、度量闭环 | 失败率、MTTR、故障数 |
