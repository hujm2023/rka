## 三、数据库系统（5-7题，重中之重）

### 3.1 关系代数（必考）

| 运算 | 符号 | 含义 |
|------|------|------|
| 选择 | σ | 横向选行（条件过滤） |
| 投影 | π | 纵向选列 |
| 并 | ∪ | 同结构合并 |
| 差 | - | A 有 B 无 |
| 笛卡尔积 | × | 全组合 |
| 自然连接 | ⋈ | 同名属性等值连接，去重 |
| θ连接 | ⋈θ | 满足条件的笛卡尔积 |
| 除 | ÷ | "全都...的" |
| 外连接 | ⟕ ⟖ ⟗ | 左/右/全外 |

**SQL ↔ 关系代数对应**：
- WHERE → σ
- SELECT(列) → π
- FROM 多表 → ×
- INNER JOIN ON → ⋈θ
- "包含全部" → ÷

### 3.2 函数依赖与候选键（必考）

**函数依赖类型**：
- **完全依赖**：X→Y 且 X 任何真子集都不能决定 Y
- **部分依赖**：X→Y 但 X 的某个真子集就能决定 Y
- **传递依赖**：X→Y, Y→Z, 则 X→Z 是传递依赖

**Armstrong 公理**：自反、增广、传递；引申：合并、分解、伪传递

**候选键求解三步法**：
1. 仅在依赖**左侧出现**的属性 → 必在候选键中
2. **未出现**在任何依赖中的属性 → 必在候选键中
3. 仅在右侧出现的属性 → 必不在候选键
4. 以上属性求闭包 = 全集 → 即为候选键；否则补充中间属性

### 3.3 范式（必考）

| 范式 | 消除 | 判定 |
|------|------|------|
| 1NF | 非原子属性 | 字段不可再分 |
| 2NF | 非主属性对码的部分依赖 | 1NF + 无部分依赖 |
| 3NF | 非主属性对码的传递依赖 | 2NF + 无传递依赖 |
| BCNF | 主属性对码的部分/传递依赖 | 所有依赖左部都含码 |
| 4NF | 多值依赖 | - |

**口诀**："1非原子、2无部分、3无传递、BC左含码"

**模式分解**：
- 无损分解：分解后能还原原关系（必须保证）
- 保持函数依赖：分解后所有原依赖仍成立
- 二元分解判定：R 分解为 R1, R2 是无损连接 ⟺ R1∩R2 → R1-R2 或 R1∩R2 → R2-R1

### 3.4 SQL 与视图

**视图的优点**：
- 简化用户操作、增加安全性、提供逻辑独立性
- 但有更新限制（多表/聚合视图通常不可更新）

**索引**：B+树索引、哈希索引、位图索引
- 适合建索引：经常查询、连接、排序的列
- 不适合：频繁更新、列基数小（如性别）

**触发器/存储过程**：在数据库端执行，减少网络开销

### 3.5 事务与并发控制

**ACID**：原子性、一致性、隔离性、持久性

**事务隔离级别**（隔离强度 低→高）：
| 级别 | 脏读 | 不可重复读 | 幻读 |
|------|------|-----------|------|
| 读未提交 RU（最低） | √ | √ | √ |
| 读已提交 RC | × | √ | √ |
| 可重复读 RR | × | × | √ |
| 可串行化 SE（最高） | × | × | × |

> 注：MySQL InnoDB 默认 RR，Oracle/SQL Server 默认 RC。√ 表示**可能出现**该异常；× 表示**已避免**。

**封锁协议**：
- 一级：写前 X 锁，事务结束释放 → 防丢失修改
- 二级：一级 + 读前 S 锁，读完释放 → 防脏读
- 三级：二级 + S 锁事务结束才放 → 防不可重复读
- **两阶段封锁(2PL)**：所有锁操作分成两个阶段(扩展期、收缩期)，可保证可串行化

**活锁/死锁**：
- 死锁解决：超时、等待图检测、按序申请

### 3.6 数据库设计

**E-R 图转关系模式**：
- 1:1：合并到任一方或单独建表
- 1:n：n端加入1端的码作为外键
- m:n：必须独立成表，键为两端码的组合
- 弱实体：依赖于强实体

### 3.7 分布式数据库

**CAP 定理**：一致性 C、可用性 A、分区容忍 P，三选二
- CA：放弃 P（单机数据库）
- CP：放弃 A（HBase, Redis哨兵, ZooKeeper）
- AP：放弃 C（最终一致，Cassandra, Eureka, DNS）

**BASE 理论**：基本可用、软状态、最终一致

**分布式事务**：
- 2PC（两阶段提交）：准备 + 提交，阻塞、单点
- 3PC：CanCommit + PreCommit + DoCommit，引入超时
- TCC（Try-Confirm-Cancel）：补偿性事务
- 最终一致性：消息表、Saga

**数据分片**：
- 水平分片（按行）、垂直分片（按列）
- 分片透明、复制透明、位置透明、逻辑透明

### 3.8 数据仓库与大数据

| 概念 | 要点 |
|------|------|
| 数据仓库特性 | 面向主题、集成、相对稳定、反映历史 |
| OLTP vs OLAP | 联机事务处理 vs 联机分析处理 |
| ETL | 抽取 Extract → 转换 Transform → 加载 Load |
| 数据挖掘 | 关联、分类、聚类、预测 |
| Lambda 架构 | 批处理层+速度层+服务层 |
| Kappa 架构 | 仅流处理（简化） |
| 数据湖 | 存原始数据、Schema-on-Read |
