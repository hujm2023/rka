## 十六、专业英语（5题）

### 高频技术词汇

**架构相关**：
- architecture, component, module, framework
- coupling（耦合）, cohesion（内聚）
- scalability（可伸缩）, availability, reliability, maintainability
- microservices, monolithic, distributed, cloud-native
- API Gateway, Service Mesh, Sidecar
- Pub/Sub, Event-driven, Message Queue

**设计相关**：
- pattern, principle, abstraction, encapsulation
- inheritance, polymorphism
- decoupling, refactoring

**敏捷相关**：
- agile, iteration, sprint, backlog, scrum
- continuous integration/delivery/deployment

**质量相关**：
- non-functional requirement, quality attribute
- performance, throughput, latency, response time
- fault tolerance, redundancy, failover
- consistency, isolation, durability

### 应试技巧
- 通读全文、找主题
- 关键词锁定段落
- 排除明显错误项
- 5 题对 3 题即可保 60% 通过
