## 八、必背速查表

### 8.1 6 大质量属性 + 战术速查

```
可用性 → 检测(心跳/Ping)、恢复(冗余/回滚)、预防(事务/监视)
性能   → 减需求、管资源(并发/副本)、调度(FIFO/优先级)
安全性 → 抵抗(认证/授权/加密)、检测(IDS)、恢复(审计)
可修改 → 局部(高内聚)、防连锁(信息隐藏)、推迟绑定(配置/插件)
可测试 → 内置监视、记录回放、接口分离
易用性 → 分离UI、用户主动(撤销/取消)
```

### 8.2 12 种架构风格速查

```
数据流：批处理、管道-过滤器
调用：主程序-子程序、OO、层次、C/S、B/S
独立：进程通信、事件驱动
虚拟机：解释器、规则
仓库：数据库、黑板、超文本
现代：SOA、微服务、REST、Serverless
```

### 8.3 ATAM 关键名词速查

```
敏感点：影响【1 个】质量属性的决策
权衡点：影响【多个】质量属性的决策
风险点：可能影响目标达成的【未确定】决策
非风险点：经过验证的合理决策
```

### 8.4 23 种设计模式速查

```
创建型(5)：单工抽建原 = 单例 + 工厂方法 + 抽象工厂 + 建造者 + 原型
结构型(7)：适桥组装外享代 = 适配器 + 桥接 + 组合 + 装饰 + 外观 + 享元 + 代理
行为型(11)：策观模命状责迭中备访解 
         = 策略+观察者+模板方法+命令+状态+责任链+迭代器+中介者+备忘录+访问者+解释器
```

### 8.5 缓存三大问题速查

```
击穿：单 key 失效 → 互斥锁、永不过期
穿透：查不存在 key → 布隆过滤器、空值缓存
雪崩：大量同时失效 → 错峰过期、多级缓存
```
