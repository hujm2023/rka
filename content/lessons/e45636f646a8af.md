## 五、数据结构与算法（3-5题）

### 5.1 时间复杂度排序

O(1) < O(logn) < O(n) < O(nlogn) < O(n²) < O(n³) < O(2^n) < O(n!)

### 5.2 排序算法（必考）

| 算法 | 平均 | 最坏 | 空间 | 稳定 | 特点 |
|------|------|------|------|------|------|
| 冒泡 | O(n²) | O(n²) | O(1) | √ | - |
| 简单选择 | O(n²) | O(n²) | O(1) | × | 比较多交换少 |
| 直接插入 | O(n²) | O(n²) | O(1) | √ | 基本有序时快 |
| 希尔 | O(n^1.3) | O(n²) | O(1) | × | - |
| 快速 | O(nlogn) | O(n²) | O(logn) | × | 平均最快 |
| 堆排序 | O(nlogn) | O(nlogn) | O(1) | × | 适合 TopK |
| 归并 | O(nlogn) | O(nlogn) | O(n) | √ | 外部排序 |
| 基数 | O(d(n+r)) | O(d(n+r)) | O(n+r) | √ | 非比较 |

**口诀**：
- 稳定：冒、插、归、基（"插冒"基归基）
- O(nlogn)：快、堆、归
- 最坏 O(nlogn)：堆、归

### 5.3 树与二叉树

**重要性质**：
- 二叉树第 i 层最多 2^(i-1) 个节点
- 深度为 k 的二叉树最多 2^k - 1 个
- 叶子数 n0 = 度2节点 n2 + 1
- 完全二叉树有 n 个节点，深度 = ⌊log₂n⌋ + 1

**遍历**：先序(根左右)、中序(左根右)、后序(左右根)
- 已知前序+中序，或中序+后序，可还原；前+后不可还原

**线索二叉树**：把空指针指向前驱/后继

**B 树/B+ 树**：
- B 树：所有节点都存数据
- B+ 树：仅叶子存数据，叶子相连便于范围查询，**数据库索引常用**

**哈夫曼树**：
- 构造：每次取最小两个合并
- WPL = ∑(权值 × 路径长度)，无度为1节点
- 编码：左 0 右 1，前缀码

**AVL 树**：左右子树高度差 ≤ 1，旋转：LL、RR、LR、RL

### 5.4 图

**最短路径**：
- Dijkstra：单源、不能负权、O(n²) 或 O(mlogn)
- Floyd：多源、可处理负权、O(n³)

**最小生成树**：
- Prim：从点扩展、稠密图、O(n²)
- Kruskal：选边、稀疏图、O(mlogm)

**拓扑排序**：AOV 网（顶点活动），无环图才有拓扑序
**关键路径**：AOE 网（边活动），最长路径=最短工期

### 5.5 查找

- 顺序查找 ASL=（n+1)/2
- 二分查找：必须有序、O(logn)、判定树
- 哈希：装填因子 α=n/m，冲突处理：开放定址、链地址

### 5.6 算法策略

| 策略 | 思想 | 例子 |
|------|------|------|
| 分治 | 分解-解决-合并 | 归并、快排、二分 |
| 动态规划 | 最优子结构+重叠子问题 | 背包、最长公共子序列 |
| 贪心 | 局部最优=全局最优 | 哈夫曼、Dijkstra、Prim |
| 回溯 | 试探+剪枝 | 八皇后、N皇后 |
| 分支限界 | BFS+剪枝 | 旅行商 |

**贪心 vs 动归**：贪心不回退、动归保留所有选择
