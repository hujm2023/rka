## 七、公式速记清单

### 挣值管理公式

| 指标 | 公式 | 含义 |
|------|------|------|
| SV | EV - PV | 进度偏差（正=提前） |
| CV | EV - AC | 成本偏差（正=节约） |
| SPI | EV / PV | 进度绩效指数（>1=提前） |
| CPI | EV / AC | 成本绩效指数（>1=节约） |
| EAC | BAC / CPI | 完工估算（按当前效率） |
| ETC | EAC - AC | 完工尚需估算 |
| VAC | BAC - EAC | 完工偏差 |

> 记忆口诀：**偏差看 EV 减，指数看 EV 除；前减后除都看 EV**

### PERT 三点估算

| 公式 | 说明 |
|------|------|
| 期望值 = (O + 4M + P) / 6 | 加权平均 |
| 标准差 σ = (P - O) / 6 | 离散程度 |
| 方差 = σ² = [(P - O) / 6]² | 用于关键路径方差计算 |

### 沟通渠道

| 公式 | 说明 |
|------|------|
| 渠道数 = N(N-1) / 2 | N 为团队人数 |

### 决策树 / 期望货币值

| 公式 | 说明 |
|------|------|
| EMV = Σ(概率 × 影响值) | 期望货币值 |

### 可用性 / 可靠性

| 指标 | 公式 |
|------|------|
| 可用性 | MTBF / (MTBF + MTTR) |
| MTBF | 平均故障间隔时间 |
| MTTR | 平均修复时间 |

### 功能点估算

| 指标 | 说明 |
|------|------|
| UFP | 未调整功能点 = Σ(信息域特征 × 权重) |
| FP | 功能点 = UFP × [0.65 + 0.01 × Σfi] |
