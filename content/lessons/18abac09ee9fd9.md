## 一、计算机组成与体系结构

### 1.1 数据表示（必考1题）

**原码、反码、补码、移码**
- 正数：原码=反码=补码（最高位0）
- 负数：反码=原码符号位不变其余取反；补码=反码+1
- 移码=补码符号位取反（用于浮点数阶码）
- n 位补码表示范围：-2^(n-1) ~ 2^(n-1)-1（多一个负数）

**浮点数**：阶码（移码）+ 尾数（原码/补码）
- 规格化：尾数最高位非0
- 对阶：小阶向大阶看齐，尾数右移

### 1.2 校验码

| 校验码 | 检错 | 纠错 | 关键 |
|-------|------|------|------|
| 奇偶校验 | 1 位 | 不能 | 简单 |
| CRC 循环冗余 | 多位 | 不能 | 模2除法 |
| 海明码 | 多位 | 1 位 | 2^k ≥ n+k+1 |

**海明码公式**：信息位 n，校验位 k，需满足 `2^k ≥ n+k+1`（k 取**最小**满足值）
- 8 位信息 → 至少 4 位校验位（2⁴=16 ≥ 8+4+1=13 ✓）
- 16 位信息 → 至少 5 位校验位（2⁵=32 ≥ 16+5+1=22 ✓）
- 32 位信息 → 至少 6 位校验位（2⁶=64 ≥ 32+6+1=39 ✓）

### 1.3 流水线（高频）

**关键公式**：
- 流水线周期 = max(各段执行时间)
- 执行 n 条指令耗时 = (k + n - 1) × Δt （k段流水线，Δt周期）
- 加速比 = 顺序时间 / 流水线时间
- 吞吐率 TP = n / 总时间，最大吞吐率 = 1/Δt
- 效率 = n×k×Δt / (k×总时间)

### 1.4 存储系统

**Cache 映射方式**：
- 直接映射：硬件简单、冲突高
- 全相联映射：灵活、硬件复杂
- 组相联映射：折中（最常用）

**Cache 替换算法**：随机、FIFO、LRU、LFU
**Cache 写策略**：写直达(Write Through)、写回(Write Back)、写一次

**主存编址计算**：
- 总容量 = 芯片容量 × 芯片数
- 芯片数 = 总容量(位) / 单片容量(位)
- 公式：地址范围 → 字节数 → 选片

### 1.5 I/O 控制方式

| 方式 | CPU占用 | 速度 |
|------|---------|------|
| 程序控制(查询) | 高 | 慢 |
| 中断 | 较高 | 中 |
| DMA | 低 | 快 |
| 通道 | 极低 | 很快 |
| I/O 处理机 | 几乎为0 | 最快 |

### 1.6 CISC vs RISC

| 特性 | CISC | RISC |
|------|------|------|
| 指令数 | 多(几百条) | 少(几十条) |
| 指令长度 | 不固定 | 固定 |
| 寻址方式 | 多 | 少 |
| 寄存器 | 少 | 多 |
| 流水线 | 不易 | 易 |
