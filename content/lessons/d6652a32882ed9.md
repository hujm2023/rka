## 第三板块：微服务核心“四梁八柱”（案例/论文万能架构图组件）
在答题或画图时，现代微服务系统必须包含以下 5 个核心组件：
```python
                    ┌────────────────────────────────────────┐
                    │            API 网关 (统一入口)          │
                    └───────────────────┬────────────────────┘
                                        │ (路由/路由限流)
                    ┌───────────────────▼────────────────────┐
                    │         服务注册中心 (Nacos / Consul)   │
                    └───────────────────┬────────────────────┘
                                        │ (动态发现)
         ┌──────────────────────────────┼──────────────────────────────┐
         ▼                              ▼                              ▼
┌──────────────────┐           ┌──────────────────┐           ┌──────────────────┐
│   微服务 A (写)   │           │   微服务 B (读)   │           │  微服务 C (其他)  │
│ ┌──────────────┐ │           │ ┌──────────────┐ │           │ ┌──────────────┐ │
│ │ 独占数据库A  │ │           │ │ 独占数据库B  │ │           │ │  断路器组件  │ │
│ └──────┬───────┘ │           │ └──────────────┘ │           │ └──────────────┘ │
└────────│─────────┘           └──────────────────┘           └──────────────────┘
         │ (发布事件)
         ▼
┌────────────────────────────────────────────────────────────────────────────────┐
│                           消息队列 (MQ / 事件驱动异步解耦)                       │
└────────────────────────────────────────────────────────────────────────────────┘
```

   1. API 网关 (API Gateway)：系统的唯一入口。负责路由、鉴权、限流、日志。
   2. 服务注册与发现 (Discovery)：服务节点的动态大管家。解决实例动态上下线后的路由问题。
   3. 断路器 (Circuit Breaker)：防雪崩利器。具备 Closed（正常） $\rightarrow$ Open（熔断降级） $\rightarrow$ Half-Open（尝试恢复） 三种状态。
   4. 配置中心 (Config)：外部化配置。实现“修改配置，实时生效，无需重启”。
   5. 消息队列 (MQ)：实现服务间的异步事件驱动风格，完成系统彻底解耦。
