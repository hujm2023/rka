## 四、设计模式应用

### 模式识别速查

| 题目关键词 | 对应模式 | 分类 |
|-----------|---------|------|
| "动态增加功能""装饰""增强" | **装饰器模式** | 结构型 |
| "一个实例""全局唯一" | **单例模式** | 创建型 |
| "创建一族相关对象" | **抽象工厂** | 创建型 |
| "将对象创建延迟到子类" | **工厂方法** | 创建型 |
| "克隆对象" | **原型模式** | 创建型 |
| "将抽象与实现分离" | **桥接模式** | 结构型 |
| "统一接口访问子系统" | **外观模式** | 结构型 |
| "控制访问""代理" | **代理模式** | 结构型 |
| "不兼容接口转换" | **适配器模式** | 结构型 |
| "状态改变时通知" | **观察者模式** | 行为型 |
| "算法家族可替换" | **策略模式** | 行为型 |
| "定义算法骨架，子类实现细节" | **模板方法** | 行为型 |

### 设计模式分类口诀

- **创建型5个**：工厂方法、抽象工厂、单例、原型、建造者
- **结构型7个**：适配器、桥接、组合、装饰器、外观、享元、代理
- **行为型11个**：策略、模板方法、观察者、状态、命令、中介者、备忘录、迭代器、访问者、职责链、解释器

> ⚠️ **易错**：桥接不是创建型！原型是创建型！
