## 七、综合答题套路（万能模板）

### 7.1 "为什么选择 X 架构/方案" 模板

```
本系统选择 [架构/方案] 的原因：

① 业务匹配：业务特征 [描述] 与该架构的优势 [描述] 匹配
② 质量属性：满足系统对 [性能/可用性/...] 的要求
③ 技术成熟：业界已有成功案例（举例）
④ 团队匹配：团队具备相关技术储备
⑤ 成本可控：[成本分析]

但需注意以下风险：
- 风险 1：[描述] → 应对：[措施]
- 风险 2：[描述] → 应对：[措施]
```

### 7.3 "提高 XX 性的方案" 模板

**性能优化**：
- 前端：CDN、压缩、合并请求
- 网络：HTTP/2、KeepAlive
- 应用：异步、并发、连接池
- 缓存：浏览器→Nginx→Redis→DB
- 数据库：索引、读写分离、分库分表
- 架构：水平扩展、负载均衡

**可用性方案**：
- 冗余设计（主备、集群）
- 容错（熔断、降级、限流）
- 监控告警（健康检查、心跳）
- 灾备（异地多活）

**安全性方案**：
- 网络层：防火墙、WAF、DDoS 防护
- 应用层：认证、授权、加密、审计
- 数据层：脱敏、加密存储、备份
- 运维层：补丁、漏洞扫描、应急响应

### 7.4 "识别风险点/敏感点/权衡点" 模板

```
针对题目给出的若干描述，逐条判别：

[描述1]：仅影响 [某个属性]，且为关键决策 → 敏感点
[描述2]：同时影响 [属性A] 和 [属性B]，需在二者间权衡 → 权衡点
[描述3]：含"可能"、"未确定"、"难以估计" → 风险点
[描述4]：明确合理且有验证 → 非风险点
```
