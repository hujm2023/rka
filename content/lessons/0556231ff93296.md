## 十二、系统可靠性（2-3题，必拿分）

### 12.1 可用性公式

```
可用性 A = MTBF / (MTBF + MTTR)
       = MTTF / (MTTF + MTTR)
```

- **MTBF**（Mean Time Between Failures）：平均故障间隔（两次故障之间）
- **MTTF**（Mean Time To Failure）：平均无故障时间（首次故障前）
- **MTTR**（Mean Time To Repair）：平均修复时间

> 💡 **记忆**：**Between**（间隔）→ MTBF；**To Failure**（到失效）→ MTTF；**To Repair**（到修好）→ MTTR。

### 12.2 可靠性串并联

**串联**：R = R1 × R2 × ... × Rn （任意一个坏全坏）
**并联**：R = 1 - (1-R1)(1-R2)...(1-Rn) （全坏才坏）
**混联**：先算并联块，再算串联

### 12.3 容错技术

- N 版本程序设计：多版本并行运行后表决
- 恢复块：主块失败 → 验证测试 → 备份块
- 防卫式程序设计：错误检测 + 损害评估 + 错误恢复
- **冗余**：硬件冗余、软件冗余、信息冗余、时间冗余

### 12.4 系统性能评估

**性能指标**：
- 响应时间、吞吐量、资源利用率
- TPS（每秒事务）、QPS（每秒查询）

**评估方法**：
- 时钟频率法、指令执行速度法（MIPS、MFLOPS）
- 等效指令法（吉布森混合法）
- 综合理论性能法（CTP）
- 基准程序法（最准）：SPEC、TPC
